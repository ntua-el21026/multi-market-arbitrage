# ADR-0017: Layered Opportunity Economics

**Status:** Superseded by ADR-0044  
**Design freeze:** v0.1 Pass 2

## Context

"The profit" can mean visible theoretical edge, full-depth upper bound, simulated capture, paper P&L, or actual live cashflow. Combining these creates misleading research.

## Decision

Persist theoretical, book-executable, simulated, paper-realized, and live-realized economics as separate layers.

## Consequences

Reports are more verbose but economically honest. Promotion can specify exactly which layer supports a conclusion.
